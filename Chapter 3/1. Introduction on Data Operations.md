# Basic Operations


The five basic arithmetic operators in C++: add, subtract, multiply, divide, and modulus.

| Operator | Name                | Example | Result |
|----------|---------------------|---------|--------|
| `+`      | Add                 | `7 + 3` | `10`   |
| `-`      | Subtract            | `7 - 3` | `4`    |
| `*`      | Multiply            | `7 * 3` | `21`   |
| `/`      | Divide              | `7 / 3` | `2`    |
| `%`      | Modulus (remainder) | `7 % 3` | `1`    |

## Example

```cpp
#include <iostream>

int main() {
    int a = 7, b = 3;

    std::cout << a + b << '\n';   // 10
    std::cout << a - b << '\n';   // 4
    std::cout << a * b << '\n';   // 21
    std::cout << a / b << '\n';   // 2
    std::cout << a % b << '\n';   // 1
    return 0;
}
```

## Add, Subtract, Multiply

These work the way you'd expect in math.

```cpp
int sum  = 7 + 3;   // 10
int diff = 7 - 3;   // 4
int prod = 7 * 3;   // 21
```

## Divide (`/`)

The result depends on the types of the operands.

- If **both** numbers are integers, the decimal part is thrown away: `7 / 3` gives `2`, not `2.33`.
- If **at least one** is a `double` (or `float`), you get a decimal result.

```cpp
int a = 7, b = 3;

std::cout << a / b << '\n';                      // 2
std::cout << 7.0 / 3 << '\n';                    // 2.33333
std::cout << static_cast<double>(a) / b << '\n'; // 2.33333
```

> **Warning:** Integer division by `0` is undefined behavior and usually crashes the program. Always check that the divisor is not zero.

## Modulus (`%`)

Gives the **remainder** after division. `7 / 3` is `2` with `1` left over, so `7 % 3` is `1`.

- Works only on integers, not on `double` or `float`.

Common uses:

```cpp
n % 2 == 0     // is n even?
n % 10         // last digit of n
i % size       // wrap an index around (0, 1, 2, 0, 1, 2, ...)
```

## Order of Operations

`*`, `/`, and `%` run before `+` and `-`. Use parentheses to change the order.

```cpp
std::cout << 2 + 3 * 4 << '\n';     // 14
std::cout << (2 + 3) * 4 << '\n';   // 20
```


# Operator Precedence and Associativity

When an expression has more than one operator, two rules decide how it is grouped:

- **Precedence**: which operator is applied first. Higher precedence binds tighter.
- **Associativity**: when operators have the **same** precedence, which direction they are grouped in (left to right, or right to left).

```cpp
int r = 2 + 3 * 4;   // * has higher precedence than +  ->  2 + (3 * 4) = 14
int s = 10 - 4 - 3;  // same precedence, left to right  ->  (10 - 4) - 3 = 3
```

---

## 1. Precedence

Higher in the table means it is applied first.

| Level | Operators                                           | Description                        | Associativity |
|-------|-----------------------------------------------------|------------------------------------|---------------|
| 1     | `::`                                                | Scope resolution                   | Left to right |
| 2     | `a++` `a--` `()` `[]` `.` `->`                      | Postfix, call, index, member access| Left to right |
| 3     | `++a` `--a` `+a` `-a` `!` `~` `(type)` `*a` `&a` `sizeof` | Prefix and unary             | Right to left |
| 4     | `*` `/` `%`                                         | Multiply, divide, modulus          | Left to right |
| 5     | `+` `-`                                             | Add, subtract                      | Left to right |
| 6     | `<<` `>>`                                           | Bit shift                          | Left to right |
| 7     | `<` `<=` `>` `>=`                                   | Relational                         | Left to right |
| 8     | `==` `!=`                                           | Equality                           | Left to right |
| 9     | `&`                                                 | Bitwise AND                        | Left to right |
| 10    | `^`                                                 | Bitwise XOR                        | Left to right |
| 11    | `\|`                                                | Bitwise OR                         | Left to right |
| 12    | `&&`                                                | Logical AND                        | Left to right |
| 13    | `\|\|`                                              | Logical OR                         | Left to right |
| 14    | `?:` `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\|=` | Ternary and assignment   | Right to left |
| 15    | `,`                                                 | Comma                              | Left to right |

> This table is simplified. It leaves out rarely used operators such as `new`, `delete`, `throw`, `.*` and `->*`.

---

## 2. Associativity

### Left to right

Most binary operators group from the left.

```cpp
10 - 4 - 3      // (10 - 4) - 3   = 3
100 / 10 / 5    // (100 / 10) / 5 = 2
100 / 10 * 5    // (100 / 10) * 5 = 50
7 % 4 * 2       // (7 % 4) * 2    = 6
```

### Right to left

Assignment, the ternary operator, and prefix/unary operators group from the right.

```cpp
int a, b, c;
a = b = c = 5;       // a = (b = (c = 5)), all three become 5

int x = 5;
int y = - -x;        // -(-x) = 5   (unary operators, right to left)
bool ok = !!x;       // !(!x) = true

// Ternary chains group from the right
int n = 15;
std::string s = n < 10 ? "small"
              : n < 20 ? "medium"
              :          "large";   // n < 10 ? "small" : (n < 20 ? "medium" : "large")
```

---

## 3. Worked Examples

### Arithmetic

```cpp
int a = 2 + 3 * 4;         // 2 + (3 * 4)   = 14
int b = (2 + 3) * 4;       // parentheses first = 20
int c = 20 / 4 * 2;        // (20 / 4) * 2  = 10
int d = 20 / (4 * 2);      // 20 / 8        = 2
int e = -2 * 3;            // (-2) * 3      = -6
```

### Shift vs. add

`+` has higher precedence than `<<`.

```cpp
int r = 1 << 2 + 1;        // 1 << (2 + 1) = 1 << 3 = 8
int s = (1 << 2) + 1;      // 4 + 1 = 5
```

### Logical operators

`!` is applied first, then `&&`, then `||`.

```cpp
bool a = true, b = false, c = false;

bool r1 = a || b && c;     // a || (b && c)  = true
bool r2 = (a || b) && c;   // false
bool r3 = !a && b;         // (!a) && b      = false
bool r4 = !(a && b);       // true
```

### Relational and equality

```cpp
int x = 5, y = 3, z = 1;

bool p = x > y == z;       // (x > y) == z   -> (true) == 1  -> true
```

### Assignment has very low precedence

```cpp
int a = 3, b = 4;
int r = a + b * 2;         // 3 + 8 = 11, then stored in r

int m = 10;
m += 2 * 3;                // m = m + (2 * 3) = 16
```

### Postfix vs. prefix with `*`

```cpp
int arr[] = {10, 20, 30};
int* p = arr;

int v = *p++;              // *(p++): read 10, then move p forward
```

---

## 4. Common Pitfalls

### 4.1 Bitwise operators vs. `==`

`==` has **higher** precedence than `&`, `^`, and `|`.

```cpp
if (6 & 3 == 3)       // 6 & (3 == 3) -> 6 & 1 -> 0  (false, probably not what you meant)
if ((6 & 3) == 3)     // 2 == 3 -> false  (what you meant, with parentheses)
```

Always wrap bitwise operations in parentheses when comparing.

### 4.2 Chained comparisons don't work like math

```cpp
int a = 1, b = 5, c = 3;

bool wrong = a < b < c;          // (a < b) < c -> true < 3 -> 1 < 3 -> true
bool right = (a < b) && (b < c); // false
```

### 4.3 `&&` binds tighter than `||`

```cpp
if (x == 1 || x == 2 && y == 3)     // x == 1 || (x == 2 && y == 3)
if ((x == 1 || x == 2) && y == 3)   // different meaning
```

### 4.4 Stream output and precedence

`<<` has higher precedence than `&`, `==`, `?:` and others, so wrap expressions in parentheses.

```cpp
std::cout << (a & b) << '\n';       // parentheses needed
std::cout << (a > b ? a : b) << '\n';
std::cout << a + b << '\n';         // fine: + is higher than <<
```

### 4.5 Precedence is not evaluation order

Precedence decides **grouping**, not which operand is evaluated first.

```cpp
int r = f() + g() * h();
// g() * h() is grouped first, but f(), g(), h() can be called in any order.
```

Modifying the same variable twice in one expression is undefined or unspecified behavior. Avoid it:

```cpp
int i = 1;
int bad = i++ + ++i;    // do not write this
```

### 4.6 Short-circuit evaluation

`&&` and `||` evaluate left to right and skip the right side if the result is already known.

```cpp
if (p != nullptr && p->value > 0) { /* safe: p->value only runs if p is not null */ }
if (x == 0 || 10 / x > 2)         { /* safe: division only runs if x is not 0 */ }
```

---

## 5. Quick Rules of Thumb

1. Unary operators (`!`, `-x`, `++x`) are applied first.
2. Then `* / %`, then `+ -`.
3. Then shifts, then comparisons (`< >`), then equality (`== !=`).
4. Then `&`, `^`, `|`, then `&&`, then `||`.
5. Ternary and assignment are last, and they group right to left.
6. If you have to think about it, **add parentheses**. They cost nothing and make code clearer.

---

## Sample Program
```cpp
#include <iostream>

int main() {
    std::cout << 8 / 2 * (2 + 2) << '\n';      // ?
    std::cout << 5 + 3 * 2 - 4 / 2 << '\n';    // ?
    std::cout << (1 << 3 | 1) << '\n';         // ?
    std::cout << (true || false && false) << '\n'; // ?
    int a, b, c;
    a = b = c = 7 % 4;
    std::cout << a << b << c << '\n';          // ?
    return 0;
}
```

2. `5 + 6 - 2` = **9**
3. `(1 << 3) | 1` = `8 | 1` = **9**
4. `true || (false && false)` = **1** (true)
5. `7 % 4` = `3`, so **333**

</details>

# Prefix and Postfix Increment and Decrement

## Regular Increment/Decrement

```cpp
int value {5};

// Increment by 1
value = value + 1;
std::cout << "The Value is: " << value << std::endl;   // 6
value = 5; // Reset the value to 5
// Decrement by 1
value = value - 1;
std::cout << "The Value is: " << value << std::endl;   // 4
```

Instead of doing `value = value + 1`, we can simply use `value++` which does the same thing as increasing by one.

Similarly instead of doing `value = value - 1` we can use `value--` which does the same thing as decreasing by 1.

```cpp
int value {5};

value++;   // same as value = value + 1  -> 6
value--;   // same as value = value - 1  -> 5
```

There is also the compound form, which works for any amount, not just 1:

```cpp
value += 3;   // value = value + 3
value -= 2;   // value = value - 2
```

---

## Two Forms: Prefix and Postfix

Both `++` and `--` can be written **before** or **after** the variable.

| Form    | Syntax              | Meaning                                    |
|---------|---------------------|--------------------------------------------|
| Postfix | `value++` `value--` | Use the current value, **then** change it  |
| Prefix  | `++value` `--value` | Change the value, **then** use it          |

On their own, as a single statement, both forms do exactly the same thing:

```cpp
int value {5};

value++;   // value is now 6
++value;   // value is now 7
```

The difference only shows up when the result is **used** in the same expression, such as being printed or assigned to another variable.

---

## Postfix (`value++` and `value--`)

The expression gives you the **old** value, and the variable changes afterwards.

```cpp
int value {5};

std::cout << value++ << std::endl;   // prints 5 (old value)
std::cout << value << std::endl;     // prints 6 (value was incremented after)
```

Step by step for `int result = value++;` with `value = 5`:

1. `result` receives the current value of `value`, which is `5`.
2. `value` is then incremented to `6`.

```cpp
int value {5};
int result = value++;

std::cout << "result: " << result << std::endl;   // 5
std::cout << "value:  " << value << std::endl;    // 6
```

Postfix decrement works the same way:

```cpp
int value {5};
int result = value--;

std::cout << "result: " << result << std::endl;   // 5
std::cout << "value:  " << value << std::endl;    // 4
```

---

## Prefix (`++value` and `--value`)

The variable changes first, and the expression gives you the **new** value.

```cpp
int value {5};

std::cout << ++value << std::endl;   // prints 6 (incremented first)
std::cout << value << std::endl;     // prints 6
```

Step by step for `int result = ++value;` with `value = 5`:

1. `value` is incremented to `6`.
2. `result` receives the new value, `6`.

```cpp
int value {5};
int result = ++value;

std::cout << "result: " << result << std::endl;   // 6
std::cout << "value:  " << value << std::endl;    // 6
```

Prefix decrement:

```cpp
int value {5};
int result = --value;

std::cout << "result: " << result << std::endl;   // 4
std::cout << "value:  " << value << std::endl;    // 4
```

---

## Side by Side

```cpp
#include <iostream>

int main() {
    int a {5};
    int b {5};

    int postfix = a++;   // postfix: take 5, then a becomes 6
    int prefix  = ++b;   // prefix:  b becomes 6, then take 6

    std::cout << "Postfix -> result: " << postfix << ", variable: " << a << std::endl;
    std::cout << "Prefix  -> result: " << prefix  << ", variable: " << b << std::endl;
    return 0;
}
```

Output:

```
Postfix -> result: 5, variable: 6
Prefix  -> result: 6, variable: 6
```

| Code                  | `value` before | Result stored | `value` after |
|-----------------------|----------------|---------------|---------------|
| `result = value++;`   | 5              | 5             | 6             |
| `result = ++value;`   | 5              | 6             | 6             |
| `result = value--;`   | 5              | 5             | 4             |
| `result = --value;`   | 5              | 4             | 4             |

An easy way to remember it: if the `++` or `--` comes **first**, the change happens **first**. If it comes **last**, the change happens **last**.

---

## Using Them Inside Larger Expressions

```cpp
int x {5};
int y = x++ + 10;   // x++ gives 5, so y = 15; then x becomes 6

int a {5};
int b = ++a + 10;   // ++a gives 6, so b = 16; a is already 6
```

```cpp
int count {3};

std::cout << "Count: " << count++ << std::endl;   // Count: 3
std::cout << "Count: " << count++ << std::endl;   // Count: 4
std::cout << "Count: " << ++count << std::endl;   // Count: 6
```

---

## In Loops

In a `for` loop the increment is a standalone statement, so prefix and postfix give the same result:

```cpp
for (int i {0}; i < 5; i++) {
    std::cout << i << " ";   // 0 1 2 3 4
}

for (int i {0}; i < 5; ++i) {
    std::cout << i << " ";   // 0 1 2 3 4
}
```

For plain `int` variables there is no practical difference. For complex types such as iterators, prefix (`++it`) is slightly more efficient because postfix has to make a temporary copy of the old value. Many C++ developers default to prefix when the result is not needed.

---

## Common Mistakes

### Using the same variable twice in one expression

```cpp
int i {1};
int bad = i++ + ++i;   // do not write this; the result is unreliable
```

Changing a variable and reading it again in the same expression leads to confusing or undefined behavior. Keep it to one `++` or `--` per variable per statement.

### Assigning a variable its own postfix result

```cpp
int value {5};
value = value++;       // confusing; do not write this
```

If you want to increase `value`, just write `value++;` or `++value;`.

### Only works on variables

The operand must be something you can modify, not a literal or a temporary result:

```cpp
int value {5};

5++;              // error: 5 is not a variable
(value + 1)++;    // error: value + 1 is a temporary result
```
