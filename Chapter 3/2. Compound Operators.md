# Compound Assignment Operators

A compound assignment operator combines a binary operation with assignment. `a op= b` means "apply `op` to `a` and `b`, then store the result in `a`".

```cpp
int x = 10;
x = x + 5;   // long form
x += 5;      // compound form
```

## The full list

| Operator | Meaning | Roughly equivalent to |
|---|---|---|
| `+=` | add and assign | `x = x + y` |
| `-=` | subtract and assign | `x = x - y` |
| `*=` | multiply and assign | `x = x * y` |
| `/=` | divide and assign | `x = x / y` |
| `%=` | remainder and assign (integers only) | `x = x % y` |
| `&=` | bitwise AND and assign | `x = x & y` |
| `\|=` | bitwise OR and assign | `x = x \| y` |
| `^=` | bitwise XOR and assign | `x = x ^ y` |
| `<<=` | left shift and assign | `x = x << y` |
| `>>=` | right shift and assign | `x = x >> y` |

C++ has no `**=`, `&&=`, `||=` or `??=`. Logical AND/OR have no compound form, and there is no exponent operator at all (use `std::pow`).



```cpp
int value {45};
std::cout << "The value is : " << value << std::endl;
```

`int value {45};` declares an integer and initializes it to 45 using brace initialization. The `cout` line prints it. The extra `std::cout << std::endl;` before each block just prints a blank line to separate the outputs.

## Step by step

Each operation works on the result of the previous one, not on the original 45.

| Statement | Equivalent to | Calculation | Result |
|---|---|---|---|
| `value += 5;` | `value = value + 5` | 45 + 5 | 50 |
| `value -= 5;` | `value = value - 5` | 50 - 5 | 45 |
| `value *= 2;` | `value = value * 2` | 45 × 2 | 90 |
| `value /= 3;` | `value = value / 3` | 90 ÷ 3 | 30 |
| `value %= 11;` | `value = value % 11` | 30 mod 11 | 8 |

The comments at the end of each `cout` line (`// 50`, `// 45`, ...) are the expected output of that line.

## Details worth noticing

- `+=` and `-=` cancel each other out here, which is why the value returns to 45.
- `/=` does integer division because `value` is an `int`. 90 / 3 divides evenly, so the result is 30. With `value /= 4` you would get 22, not 22.5, since the fractional part is discarded.
- `%=` stores the remainder. 11 goes into 30 twice (22), leaving 8.

## Full code

```cpp
#include <iostream>

int main() {
    int value {45};
    std::cout << "The value is : " << value << std::endl;

    std::cout << std::endl;
    value += 5; // equivalent to value = value + 5
    std::cout << "The value is (after +=5) : " << value << std::endl; // 50

    std::cout << std::endl;
    value -= 5; // equivalent to value = value - 5
    std::cout << "The value is (after -=5) : " << value << std::endl; // 45

    std::cout << std::endl;
    value *= 2;
    std::cout << "The value is (after *=2) : " << value << std::endl; // 90

    std::cout << std::endl;
    value /= 3;
    std::cout << "The value is (after /=3) : " << value << std::endl; // 30

    std::cout << std::endl;
    value %= 11;
    std::cout << "The value is (after %=11) : " << value << std::endl; // 8

    return 0;
}
```

## Expected output

```
The value is : 45

The value is (after +=5) : 50

The value is (after -=5) : 45

The value is (after *=2) : 90

The value is (after /=3) : 30

The value is (after %=11) : 8
```

## Note on `std::endl`

`std::endl` prints a newline and also flushes the output buffer. It works fine here, but `'\n'` is usually preferred when you don't need the flush.v
