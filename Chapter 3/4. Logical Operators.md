
# Logical Operators

Logical operators are used to **combine multiple conditions or reverse a condition**.

They are particularly useful when we want to check more than one condition at a time.

For example:

- A student must score more than 40 marks in Mathematics AND Physics.
- A person can enter if they have a student ID OR an employee ID.
- A user is NOT an administrator.

C++ provides three main logical operators.

## Types of Logical Operators

| Operator | Name | Description |
|---|---|---|
| `&&` | Logical AND | Returns true if both conditions are true |
| `||` | Logical OR | Returns true if at least one condition is true |
| `!` | Logical NOT | Reverses the result of a condition |

## 1. Logical AND (`&&`)

The AND operator returns `true` only when **both conditions are true**.

### Truth Table

| Condition A | Condition B | A && B |
|---|---|---|
| true | true | true |
| true | false | false |
| false | true | false |
| false | false | false |

### Example

```cpp
#include <iostream>

int main()
{
    int age = 20;
    bool hasID = true;

    std::cout << std::boolalpha;

    std::cout << (age >= 18 && hasID) << std::endl;

    return 0;
}
```

**Output**

```text
true
```

Explanation:

- `age >= 18` is true.
- `hasID` is true.
- Both conditions are true, so the final result is true.

If either condition becomes false, the entire expression becomes false.

## 2. Logical OR (`||`)

The OR operator returns `true` if **at least one condition is true**.

### Truth Table

| Condition A | Condition B | A || B |
|---|---|---|
| true | true | true |
| true | false | true |
| false | true | true |
| false | false | false |

### Example

```cpp
#include <iostream>

int main()
{
    bool hasStudentID = false;
    bool hasEmployeeID = true;

    std::cout << std::boolalpha;

    std::cout << (hasStudentID || hasEmployeeID) << std::endl;

    return 0;
}
```

**Output**

```text
true
```

Explanation:

- `hasStudentID` is false.
- `hasEmployeeID` is true.
- At least one condition is true, so the final result is true.

## 3. Logical NOT (`!`)

The NOT operator reverses the Boolean result.

- If the condition is true, it becomes false.
- If the condition is false, it becomes true.

### Truth Table

| Condition A | !A |
|---|---|
| true | false |
| false | true |

### Example

```cpp
#include <iostream>

int main()
{
    bool isRaining = false;

    std::cout << std::boolalpha;

    std::cout << !isRaining << std::endl;

    return 0;
}
```

**Output**

```text
true
```

Explanation:

`isRaining` is false, so `!isRaining` reverses it and returns true.

## Combining Logical and Relational Operators

We can combine relational operators with logical operators to create more complex conditions.

### Example: Student Eligibility

A student is eligible if:

- Their marks are greater than or equal to 40.
- Their attendance is greater than or equal to 75%.

Both conditions must be satisfied.

```cpp
#include <iostream>

int main()
{
    int marks = 45;
    int attendance = 80;

    bool eligible = (marks >= 40 && attendance >= 75);

    std::cout << std::boolalpha;
    std::cout << "Eligible: " << eligible << std::endl;

    return 0;
}
```

**Output**

```text
Eligible: true
```

## Short-Circuit Evaluation

C++ has a feature called **short-circuit evaluation**.

It means that C++ sometimes stops evaluating an expression once the final result is already known.

### With AND (`&&`)

If the first condition is false, C++ does not need to check the second condition because the final result will always be false.

```cpp
#include <iostream>

int main()
{
    int a = 5;

    if (a > 10 && a < 20)
    {
        std::cout << "Both conditions are true";
    }

    return 0;
}
```

Since `a > 10` is false, the second condition is not evaluated.

### With OR (`||`)

If the first condition is true, C++ does not need to check the second condition because the final result will always be true.

```cpp
#include <iostream>

int main()
{
    int a = 15;

    if (a > 10 || a < 5)
    {
        std::cout << "At least one condition is true";
    }

    return 0;
}
```

Since `a > 10` is true, the second condition is not evaluated.

> **Note:** Short-circuit evaluation is useful because it can prevent unnecessary calculations and avoid certain errors.

## Operator Precedence

When multiple logical operators are used together, C++ follows a specific order of evaluation.

| Operator | Precedence |
|---|---|
| `!` | Highest |
| `&&` | Next |
| `||` | Lowest |

For example:

```cpp
bool result = true || false && false;
```

The `&&` operator is evaluated first.

Therefore:

```text
true || (false && false)
true || false
true
```

**Tip:** Use parentheses `()` whenever an expression becomes complicated. They make the intended order easier to understand.

## Note

- Logical operators combine or reverse conditions.
- `&&` requires both conditions to be true.
- `||` requires at least one condition to be true.
- `!` reverses a Boolean result.
- Short-circuit evaluation skips unnecessary condition checks.
- Logical operators are commonly used with relational operators.
