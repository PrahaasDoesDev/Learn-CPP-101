# Relational Operators

Relational operators are used to **compare two values**. They check the relationship between two operands and return a Boolean result (`true` or `false`).

For example, if we compare `10` and `5`, the expression `10 > 5` returns `true`.

## Types of Relational Operators

| Operator | Name | Description | Example | Result |
|---|---|---|---|---|
| `==` | Equal to | Checks if two values are equal | `10 == 10` | `true` |
| `!=` | Not equal to | Checks if two values are different | `10 != 5` | `true` |
| `>` | Greater than | Checks if left value is greater | `10 > 5` | `true` |
| `<` | Less than | Checks if left value is smaller | `5 < 10` | `true` |
| `>=` | Greater than or equal to | Checks if left value is greater or equal | `10 >= 10` | `true` |
| `<=` | Less than or equal to | Checks if left value is smaller or equal | `5 <= 10` | `true` |

## Example

```cpp
#include <iostream>

int main()
{
    int firstNumber = 10;
    int secondNumber = 5;

    std::cout << (firstNumber == secondNumber) << std::endl;
    std::cout << (firstNumber != secondNumber) << std::endl;
    std::cout << (firstNumber > secondNumber) << std::endl;
    std::cout << (firstNumber < secondNumber) << std::endl;
    std::cout << (firstNumber >= secondNumber) << std::endl;
    std::cout << (firstNumber <= secondNumber) << std::endl;

    return 0;
}
```

### Output

```text
0
1
1
0
1
0
```

By default, C++ prints Boolean values as:

- `1` = `true`
- `0` = `false`

### Printing true and false instead of 1 and 0

C++ provides `std::boolalpha` to display Boolean values as words.

```cpp
#include <iostream>

int main()
{
    int a = 10;
    int b = 5;

    std::cout << std::boolalpha;

    std::cout << (a > b) << std::endl;
    std::cout << (a == b) << std::endl;

    return 0;
}
```

**Output**

```text
true
false
```

## Common Mistake: `=` vs `==`

These two operators have completely different purposes.

| Operator | Purpose |
|---|---|
| `=` | Assignment operator (assigns a value) |
| `==` | Relational operator (compares two values) |

```cpp
int a = 10;     // Assigns 10 to a

std::cout << (a == 10);  // Checks whether a is equal to 10
```

> **Important:** Using `=` instead of `==` when comparing values is a common beginner mistake.

## Practical Example: Checking Eligibility

```cpp
#include <iostream>

int main()
{
    int age;

    std::cout << "Enter your age: ";
    std::cin >> age;

    std::cout << std::boolalpha;

    std::cout << "Are you eligible to vote? "
              << (age >= 18) << std::endl;

    return 0;
}
```

**Output 1**

```text
Enter your age: 20
Are you eligible to vote? true
```

**Output 2**

```text
Enter your age: 15
Are you eligible to vote? false
```

## Note

- Relational operators are used to compare two values.
- They always produce a Boolean result (`true` or `false`).
- `==` checks equality, whereas `=` assigns a value.
- `std::boolalpha` displays Boolean values as `true` and `false` instead of `1` and `0`.
