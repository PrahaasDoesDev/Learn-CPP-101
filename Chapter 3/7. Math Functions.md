# Math Functions in C++

C++ provides common mathematical functions in the `<cmath>` header.

```cpp
#include <cmath>
```

The functions covered here are:

| Group | Functions |
|---|---|
| Rounding | `std::floor()`, `std::ceil()`, `std::round()` |
| Absolute value | `std::abs()` |
| Powers and roots | `std::pow()`, `std::sqrt()` |
| Exponential and logarithm | `std::exp()`, `std::log()` |
| Trigonometry | `std::sin()`, `std::cos()`, `std::tan()` |

Unless stated otherwise, these functions take and return floating-point values (`double`, `float`, `long double`). If you pass an `int`, it is converted to `double` first.

## 1. Rounding Functions

### `std::floor()`

Rounds **down** to the nearest whole number (towards negative infinity).

```cpp
std::floor(3.7);    // 3.0
std::floor(-3.2);   // -4.0
```

### `std::ceil()`

Rounds **up** to the nearest whole number (towards positive infinity).

```cpp
std::ceil(3.2);     // 4.0
std::ceil(-3.7);    // -3.0
```

### `std::round()`

Rounds to the **nearest** whole number. Halfway values round **away from zero**.

```cpp
std::round(3.4);    // 3.0
std::round(3.5);    // 4.0
std::round(-3.5);   // -4.0
std::round(2.5);    // 3.0
```

> **Note:** In the slide, `std::round` is written without parentheses. It is a function, so you always call it as `std::round(value)`.

### Comparison

| Value | `floor` | `ceil` | `round` | `trunc` (bonus) |
|---|---|---|---|---|
| `3.2` | `3` | `4` | `3` | `3` |
| `3.7` | `3` | `4` | `4` | `3` |
| `-3.2` | `-4` | `-3` | `-3` | `-3` |
| `-3.7` | `-4` | `-3` | `-4` | `-3` |
| `2.5` | `2` | `3` | `3` | `2` |
| `-2.5` | `-3` | `-2` | `-3` | `-2` |

`std::trunc()` simply removes the fractional part (rounds towards zero).

> **Important:** These functions return a **floating-point** value, not an `int`. Use `static_cast<int>(...)` if you need an integer.

```cpp
int rounded = static_cast<int>(std::round(3.7));   // 4
```

## 2. `std::abs()`

Returns the **absolute value**, which is the distance from zero (always non-negative).

```cpp
std::abs(-7.5);   // 7.5
std::abs(7.5);    // 7.5
std::abs(-4);     // 4
```

- The floating-point versions are in `<cmath>`.
- The integer versions (`int`, `long`) are in `<cstdlib>`, and `<cmath>` also provides overloads for them in modern C++.
- Always write `std::abs`, because plain `abs` may pick the integer version and silently truncate a `double`.

## 3. Powers and Roots

### `std::pow(base, exponent)`

Raises a number to a power: `base^exponent`.

```cpp
std::pow(2, 10);     // 1024.0   (2 to the power 10)
std::pow(9, 0.5);    // 3.0      (square root of 9)
std::pow(2, -1);     // 0.5      (1 / 2)
std::pow(5, 0);      // 1.0
```

### `std::sqrt(x)`

Returns the **square root** of `x`.

```cpp
std::sqrt(16);    // 4.0
std::sqrt(2);     // 1.41421...
std::sqrt(-1);    // nan (not a number): no real square root
```

> **Tip:** `std::sqrt(x)` is clearer and usually faster than `std::pow(x, 0.5)`.

## 4. Exponential and Logarithm

### `std::exp(x)`

Returns **e raised to the power x** (`e^x`), where `e ≈ 2.71828`.

```cpp
std::exp(0);    // 1.0
std::exp(1);    // 2.71828...
std::exp(2);    // 7.38905...
```

### `std::log(x)`

Returns the **natural logarithm** (base `e`) of `x`. It is the inverse of `std::exp()`.

```cpp
std::log(1);                // 0.0
std::log(std::exp(1));      // 1.0
std::log(10);               // 2.30258...
```

Special cases:

| Call | Result |
|---|---|
| `std::log(0)` | `-inf` |
| `std::log(-5)` | `nan` |

> **Warning:** `std::log()` is the natural logarithm, **not** base 10. Use `std::log10()` for base 10 and `std::log2()` for base 2.

```cpp
std::log10(1000);   // 3.0
std::log2(8);       // 3.0
```

## 5. Trigonometric Functions

`std::sin()`, `std::cos()` and `std::tan()` take the angle in **radians**, not degrees.

```cpp
std::sin(x);   // sine
std::cos(x);   // cosine
std::tan(x);   // tangent = sin(x) / cos(x)
```

### Converting degrees to radians

```
radians = degrees × π / 180
```

```cpp
const double pi = std::acos(-1.0);        // 3.14159265358979...
double degrees = 30.0;
double radians = degrees * pi / 180.0;

std::sin(radians);   // 0.5 (approximately)
```

(In C++20 you can use `std::numbers::pi` from `<numbers>` instead.)

### Common values

| Angle | `sin` | `cos` | `tan` |
|---|---|---|---|
| 0° | `0` | `1` | `0` |
| 30° | `0.5` | `0.866` | `0.577` |
| 45° | `0.707` | `0.707` | `1` |
| 60° | `0.866` | `0.5` | `1.732` |
| 90° | `1` | `0` | undefined (very large value) |

### Floating-point caveat

Results are approximate, so you will not always get an exact value:

```cpp
std::sin(pi);   // about 1.22e-16, not exactly 0
```

Do not compare such results with `==`. Compare using a small tolerance instead:

```cpp
if (std::abs(std::sin(pi)) < 1e-9) { /* treat as zero */ }
```

### Inverse functions (bonus)

| Function | Meaning |
|---|---|
| `std::asin(x)` | Inverse sine (returns radians) |
| `std::acos(x)` | Inverse cosine (returns radians) |
| `std::atan(x)` | Inverse tangent (returns radians) |
| `std::atan2(y, x)` | Angle of the point `(x, y)`, handles all quadrants |

## 6. Complete Example

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>

int main()
{
    const double pi = std::acos(-1.0);

    std::cout << std::fixed << std::setprecision(4);

    std::cout << "floor(3.7)      = " << std::floor(3.7)        << "\n";
    std::cout << "ceil(3.2)       = " << std::ceil(3.2)         << "\n";
    std::cout << "round(3.5)      = " << std::round(3.5)        << "\n";
    std::cout << "abs(-7.5)       = " << std::abs(-7.5)         << "\n";
    std::cout << "sqrt(16)        = " << std::sqrt(16.0)        << "\n";
    std::cout << "pow(2, 10)      = " << std::pow(2.0, 10.0)    << "\n";
    std::cout << "exp(1)          = " << std::exp(1.0)          << "\n";
    std::cout << "log(e)          = " << std::log(std::exp(1.0)) << "\n";
    std::cout << "log10(1000)     = " << std::log10(1000.0)     << "\n";
    std::cout << "sin(30 degrees) = " << std::sin(pi / 6)       << "\n";
    std::cout << "cos(0)          = " << std::cos(0.0)          << "\n";
    std::cout << "tan(45 degrees) = " << std::tan(pi / 4)       << "\n";

    return 0;
}
```

**Output**

```text
floor(3.7)      = 3.0000
ceil(3.2)       = 4.0000
round(3.5)      = 4.0000
abs(-7.5)       = 7.5000
sqrt(16)        = 4.0000
pow(2, 10)      = 1024.0000
exp(1)          = 2.7183
log(e)          = 1.0000
log10(1000)     = 3.0000
sin(30 degrees) = 0.5000
cos(0)          = 1.0000
tan(45 degrees) = 1.0000
```

## Quick Reference

| Function | Purpose | Example | Result |
|---|---|---|---|
| `std::floor(x)` | Round down | `std::floor(3.7)` | `3.0` |
| `std::ceil(x)` | Round up | `std::ceil(3.2)` | `4.0` |
| `std::round(x)` | Round to nearest | `std::round(3.5)` | `4.0` |
| `std::abs(x)` | Absolute value | `std::abs(-7.5)` | `7.5` |
| `std::sqrt(x)` | Square root | `std::sqrt(16)` | `4.0` |
| `std::pow(b, e)` | Power | `std::pow(2, 10)` | `1024.0` |
| `std::exp(x)` | e to the power x | `std::exp(1)` | `2.71828...` |
| `std::log(x)` | Natural logarithm | `std::log(1)` | `0.0` |
| `std::sin(x)` | Sine (radians) | `std::sin(0)` | `0.0` |
| `std::cos(x)` | Cosine (radians) | `std::cos(0)` | `1.0` |
| `std::tan(x)` | Tangent (radians) | `std::tan(0)` | `0.0` |

## Note

- All of these functions are in the `<cmath>` header.
- `floor`, `ceil` and `round` return floating-point values, so cast to `int` if you need an integer.
- `std::round` rounds halfway values away from zero.
- `std::log()` is the natural logarithm. Use `std::log10()` or `std::log2()` for other bases.
- `std::sqrt()` of a negative number and `std::log()` of a negative number both give `nan`.
- Trigonometric functions use **radians**, so convert degrees with `degrees * π / 180`.
- Floating-point results are approximate, so compare with a tolerance rather than `==`.
