
# Integer Modifiers

Lets now talk about how we can store positive and negative numbers.

```cpp
int value1 {10};
int value2 {-200};
```
Both the above mentioned values are valid 

```cpp
signed int value1 {10};
signed int value2 {-200};
```

`signed` is a modifier which signals that we have the possibility to store negative or positive numbers.


# Signed and unsigned ranges

`n` = number of bits

- unsigned: `0` to `2^n - 1`
- signed: `-2^(n-1)` to `2^(n-1) - 1`

## basic idea

- n bits give `2^n` possible values
- unsigned uses all of them for 0 and positive numbers
- signed splits them: half negative, half for 0 and positive
- that's why signed has one more negative than positive (0 takes a spot on the positive side)

## example (8 bits)

- unsigned: `0` to `255`
- signed: `-128` to `127`

## common sizes

| bits | unsigned | signed |
|---|---|---|
| 8 | 0 to 255 | -128 to 127 |
| 16 | 0 to 65,535 | -32,768 to 32,767 |
| 32 | 0 to 4,294,967,295 | -2,147,483,648 to 2,147,483,647 |

## in C++

- `int` is usually 32 bits, so `-2,147,483,648` to `2,147,483,647`
- `unsigned int` is 32 bits, `0` to `4,294,967,295`
- going past the range is overflow: unsigned wraps around, signed is undefined behavior

```cpp
unsigned char x = 255;
x++;   // wraps to 0
```



# Integer types in C++

four integer types, from smallest to biggest: `short`, `int`, `long`, `long long`

each one can be signed (default) or unsigned.

## how the names work

- `int` is optional with `short`, `long`, `long long`. `short` = `short int`
- `signed` is the default. `int` = `signed int` = `signed`
- `unsigned` = no negatives, positive range doubles
- all of these are the same type:

```cpp
short a;  short int b;  signed short c;  signed short int d;
```

## short

- 2 bytes (16 bits)
- signed: `-32,768` to `32,767`
- unsigned: `0` to `65,535`
- use when you want to save memory, like big arrays of small numbers

```cpp
short s {-32768};
unsigned short us {456};
```

## int

- 4 bytes (32 bits) on most systems
- signed: `-2,147,483,648` to `2,147,483,647`
- unsigned: `0` to `4,294,967,295`
- the default choice for whole numbers

```cpp
int i {55};
unsigned int ui {77};
```

## long

- 4 or 8 bytes, depends on the platform
  - windows: 4 bytes (same as `int`)
  - 64-bit linux / mac: 8 bytes
- because the size changes, don't rely on it if the range matters

```cpp
long l {88};
unsigned long ul {44};
```

## long long

- 8 bytes (64 bits) everywhere
- signed: about `-9.2 quintillion` to `9.2 quintillion` (`-2^63` to `2^63 - 1`)
- unsigned: `0` to about `18.4 quintillion` (`2^64 - 1`)
- use for really big numbers, like factorials or large sums

```cpp
long long ll {888};
unsigned long long ull {1234};
```

## quick table

| type | size | notes |
|---|---|---|
| `short` | 2 bytes | small numbers |
| `int` | 4 bytes | default |
| `long` | 4 or 8 bytes | size depends on platform |
| `long long` | 8 bytes | very large numbers |

## the `{ }` part

```cpp
int x {55};
```

- this is brace initialization, it sets the starting value
- works like `int x = 55;`, but it gives an error if the value doesn't fit

```cpp
short s {40000};      // error, too big for short
unsigned int u {-5};  // error, negative in unsigned
```

## check sizes on your machine

```cpp
#include <iostream>

int main() {
    std::cout << sizeof(short) << "\n";       // 2
    std::cout << sizeof(int) << "\n";         // 4
    std::cout << sizeof(long) << "\n";        // 4 or 8
    std::cout << sizeof(long long) << "\n";   // 8
}
```

## what to use

- normal whole numbers: `int`
- really big numbers: `long long`
- need only positives: add `unsigned`
- skip writing `signed` and the extra `int`, use `short`, `long`, `long long` directly

> **Note:** These modifiers only apply to integral types: those in which you can store decimal numbers
