# Booleans

Booleans are types that can store two states in C++, it can store either true or false values

### General Syntax

```cpp
bool variableName {true/false};
```

### Printing out a boolean
- 1 --->> True
- 0 --->> False
- Booleans occupy 8 bits in memory, they take up an entire byte.
  

- A byte can store 256 different values
- Using it just to cover two states (true/false) is wasteful, especially for devices with hard memory constraints (think embedded devices)
- There are techniques to pack even more data into a byte. We'll learn more about these in the upcoming chapters
