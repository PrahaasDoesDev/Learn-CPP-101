# Assignments

The basic idea, is that after a variable is declared it can be reassigned a value again later on in the program.

For example
```cpp
int var1{123};
std::cout << "Var1: " << var1 << std::endl;

var1 = 55; //Assigning a new value
std::cout << "Var1: " << var1 << std::endl;
```

The idea here is that initially the value assigned to var1 was 123 and later in the program we assigned a new value to var1 which is 55. When we print the value of the variable after the assignment it will outpu 55 and not 123, since we had changed the value of the variable.

This implies a variable can be assigned two different values at different times of the program, and it will always print the latest assigned value.

> **Note:** One thing you need to be careful about is when you are using `auto` to detect values, the type is not  very apparent by looking at the declaration for example:


```cpp
auto var3 {333u}; //Declare and initialize with type deduction 
var3 = -22; // Assign Negative number, DANGER!
std::cout << "Var3:  " << var3 << std::endl;
```
