# Characters and Text

In C++ we use the datatype `char` to represent characters.
For example
```cpp
char character1 = {'h'};
char character2 = {'e'};
char character3 = {'l'};
char character4 = {'l'};
char character5 = {'o'};
```

You need to put the characters in `''` so that the compiler knows its a character otherwise it will give an error.


Which means we can do something like this

- `char` occupies 1 byte in memory
- 1 byte = 8 bits, so it can hold 2⁸ = 256 possible values
- One thing we can do is map each value in these 256 possible values to a character

Which means we can do something like this

| Number | Character |
|--------|-----------|
| 65     | `A`       |
| 66     | `B`       |
| 97     | `a`       |
| 104    | `h`       |

This mapping is called **ASCII** (American Standard Code for Information Interchange).

- ASCII defines the values `0`-`127`
- `0`-`31` and `127` are control characters (newline, tab, etc.)
- `32`-`126` are printable characters (space, digits, letters, symbols)
- `128`-`255` are used by extended encodings, which differ between systems

## A `char` is just a small number

`'h'` and `104` are the same value in memory:

```cpp
#include <iostream>
using namespace std;

int main() {
    char c = 104;
    cout << c << endl;              // h

    char d = 'h';
    cout << (int)d << endl;         // 104

    char e = 'A';
    cout << e + 1 << endl;          // 66  (e is promoted to int)
    cout << (char)(e + 1) << endl;  // B
}
```

> Arithmetic on a `char` produces an `int`. Cast back to `char` to print the character.

## Why the quotes matter

```cpp
char a = 'h';   // OK: character literal
char b = "h";   // error: "h" is a string, not a char
char c = h;     // error: h is not declared
```

- `'h'` is a character literal and the compiler gives it the value `104`
- Without quotes, `h` is treated as a variable name
- Double quotes `"h"` create a string, which is a different type

## Signed vs unsigned

| Type            | Range        |
|-----------------|--------------|
| `unsigned char` | 0 to 255     |
| `signed char`   | -128 to 127  |
| `char`          | either, depends on the compiler |

## Useful tricks

```cpp
int digit = '5' - '0';   // 53 - 48 = 5
char lower = 'B' + 32;   // 66 + 32 = 98 -> 'b'
char upper = 'b' - 32;   // 98 - 32 = 66 -> 'B'
```

- Digit characters `'0'`-`'9'` are consecutive (48-57)
- Uppercase and lowercase letters always differ by 32
- It is possible to assign a valid ASCII code to a char variable, and the corresponding character will be stored in. You can choose to interpret that either as a character or as a regular integral value.

<hr>

When we do `char value = 65` it will print the ASCII character code for whatever the assigned value for 65 is in the ASCII Table. (Here in this case A).

However there is a way to turn that into an integer and print it out, this is achieved by using
`static_cast<int>(variable)`

Example: 
```cpp
char value = 65;
std::cout << "Value: " << value std::endl;
std::cout << "Value(int): " << static_cast<int>(value) std::endl;
```

- ASCII was among the first encodings to represent text in a computer.
- It falls short when it comes to representing languages other than english and a few western languages. Think Arabic, Japanese, Chinese...
